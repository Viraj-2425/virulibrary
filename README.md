# Virulibrary
📚 VIRULIBRARY

A modern, responsive digital library landing page built using HTML5 and CSS3. The project features a clean user interface with glassmorphism cards, smooth animations, and a fully responsive layout for desktop, tablet, and mobile devices.

✨ Features
📱 Fully Responsive Design
📚 Modern Library Landing Page
🎨 Beautiful Orange Gradient Theme
🌄 Full-Screen Unsplash Background Image
🪟 Glassmorphism Information Cards
✨ Smooth Hover Effects & CSS Animations
📩 Email Subscription Section
🚀 Clean and Well-Organized Code

🛠️ Technologies Used
HTML5
CSS3
Google Fonts (Poppins)
Unsplash Images
